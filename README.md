# To-Do List Web Application

A sleek, intuitive, and highly functional To-Do List application designed to help you organize your tasks efficiently. Built using vanilla HTML, CSS, and JavaScript, this project demonstrates modern web development practices including responsive design, local storage persistence, and interactive UI/UX.

## 🚀 Features

* **Task Management:**
    * Add new tasks with descriptions.
    * Edit existing task details.
    * Delete tasks permanently.
    * Mark tasks as completed with a distinct visual style (strike-through and faded).
    * Assign categories (e.g., Personal, Work, Shopping) to tasks.
    * Set priority levels (Low, Medium, High, Urgent) with visual indicators.
    * Add due dates to tasks, with overdue tasks highlighted.

* **Task Filtering:**
    * View all tasks (pending by default).
    * Filter tasks due "Today".
    * See "Upcoming" tasks due in the future.
    * Browse "Completed" tasks.

* **Intuitive UI/UX:**
    * **Dark/Light Mode Toggle:** Switch themes seamlessly for personalized viewing.
    * **Responsive Design:** Optimized for a flawless experience across desktops, tablets, and mobile devices (mobile-first approach).
    * **Micro-interactions & Hover Effects:** Subtle animations for buttons, task cards, and interactive elements enhance user engagement.
    * **Visual Task Cards:** Each task is presented in a well-styled card format, reflecting its status (completed, overdue, etc.).
    * **Drag-and-Drop Placeholder:** A visual cue indicating potential reordering capabilities (feature not actively implemented in JS but designed for future expansion).

* **Productivity Statistics:**
    * Real-time display of total tasks.
    * Count of completed tasks.
    * Count of pending tasks.

* **Data Persistence:**
    * All tasks and your theme preference are saved in your browser's Local Storage, so your data remains even after closing the browser.

* **Accessibility:**
    * Semantic HTML5 structure for better document outline and SEO.
    * Appropriate ARIA labels for improved screen reader compatibility.
    * Basic keyboard navigation support for interactive elements.

* **Code Quality:**
    * Clean, well-commented, and organized codebase.
    * Separation of concerns (HTML for structure, CSS for styling, JavaScript for logic).
    * Consistent color themes, spacing, and border-radius using CSS variables.

## 🛠️ Technologies Used

* **HTML5:** For the core structure and content.
* **CSS3:** For styling, including custom properties (variables), Flexbox, Grid, and Media Queries.
* **JavaScript (ES6+):** For all dynamic functionalities and data management.
* **Font Awesome:** For scalable vector icons.

## 🚀 Getting Started

To run this project locally, follow these simple steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/ashishsadavarti0709/To-Do-List-Using-HTML-CSS-JavaScript
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd todo-list
    ```
3.  **Open `index.html`:**
    Open the `index.html` file in your preferred web browser. All necessary CSS and JavaScript files are linked relative to the HTML file.
